Completely rewrite `frontend/src/routes/api/chat/+server.ts`. Remove all OpenAI code. The new implementation:

**Request format:**
```typescript
interface ChatRequest {
  messages: Array<{ role: 'user' | 'assistant'; content: string }>;
  model?: ModelKey; // from frontend model selector, default 'sonnet-4.6'
}
```

**System prompt:**
```
You are an AI investigation assistant analyzing the Epstein document corpus — over 960,000 documents including court filings, depositions, flight logs, correspondence, and financial records.

Your tools give you direct access to search the documents, find entities, and traverse the knowledge graph. USE THEM PROACTIVELY — do not answer from memory. Every factual claim must be supported by documents you retrieved.

Available tools:
- search_documents: Full-text search across the document corpus
- semantic_search: Find conceptually similar documents using vector embeddings
- get_entity_profile: Look up people, organizations, and locations in the knowledge graph
- graph_query: Traverse relationships between entities
- find_connections: Discover paths between two entities

When you retrieve documents, your citations will be automatically generated from the search results. Always provide specific, evidence-based answers grounded in the documents you find.

If you cannot find relevant documents for a claim, explicitly state that the information is not supported by the corpus.
```

**Implementation flow:**

1. Parse request body. Validate messages array is non-empty.
2. Get model from request body, default to `DEFAULT_MODEL`. Map to model ID via `CLAUDE_MODELS[model]`.
3. Create Anthropic client via `createAnthropicClient(platform)`.
4. Apply sliding window (SEC-10): Keep first message + last 5 messages from the conversation. For tool_use/tool_result message pairs within the window, keep both.
5. Convert messages to Anthropic format: `{ role: 'user' | 'assistant', content: string }[]`
6. Create TransformStream for SSE response.
7. In background async:
   a. Set `currentMessages` to the bounded messages.
   b. Loop up to `MAX_ITERATIONS = 5`:
      - Call `anthropic.messages.stream({ model, max_tokens: 4096, system: SYSTEM_PROMPT, tools: toolDefinitions, messages: currentMessages })`
      - Iterate over stream events:
        - `content_block_start` with `type: 'tool_use'`: Write SSE `event: tool_call` with `{id, name}`
        - `content_block_delta` with `type: 'input_json_delta'`: Accumulate tool input JSON (don't stream this to client)
        - `content_block_delta` with `type: 'text_delta'`: Write SSE `event: text_delta` with `{text: delta.text}`
        - `content_block_delta` with `type: 'citations_delta'`: Write SSE `event: citations_delta` with `{citation: delta.citation}`
      - Get `finalMessage` from `stream.finalMessage()`.
      - If `finalMessage.stop_reason === 'tool_use'`:
        - Extract tool_use blocks from `finalMessage.content`
        - Execute all tools in parallel: `Promise.all(toolUseBlocks.map(block => executeTool(block.name, block.input, platform)))`
        - For each tool result, write SSE `event: tool_result` with `{id: block.id, name: block.name, status: 'complete', resultCount: results.length}`
        - Build tool_result messages and append to `currentMessages`:
          - `{ role: 'assistant', content: finalMessage.content }`
          - `{ role: 'user', content: toolUseBlocks.map((block, i) => ({ type: 'tool_result', tool_use_id: block.id, content: toolResults[i] })) }`
        - Continue loop
      - Else (stop_reason is 'end_turn' or 'max_tokens'): break loop
   c. Write SSE `event: done` with `{model: selectedModelId}`.
   d. Close writer.
8. Return Response with SSE headers: `Content-Type: text/event-stream`, `Cache-Control: no-cache, no-transform`, `X-Accel-Buffering: no`, `Connection: keep-alive`.

**Error handling:**
- Wrap entire stream in try/catch. On error, write SSE `event: error` with `{message: error.message}` then close.
- If a tool execution fails, return the error as a text search_result: `[{type: 'search_result', source: 'error', title: 'Tool Error', content: [{type: 'text', text: 'Error: {message}'}], citations: {enabled: false}}]`
- Handle stream interruption (missing message_stop) gracefully — write done event anyway.

**Key decisions:**
- Do NOT import or use OpenAI SDK anywhere — fully remove the dependency.
- Do NOT pre-fetch embeddings or documents — let Claude decide which tools to call.
- requireAuth middleware should be applied if it exists (check hooks.server.ts pattern).
