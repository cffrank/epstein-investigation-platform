  <name>Task 2: Enhance server data loading for dossier</name>
  <files>frontend/src/routes/(app)/entities/[id]/+page.server.ts</files>
  <action>
Refactor the existing +page.server.ts to return EntityDossier data:

1. **Update the profile Cypher query** to also fetch `e.aliases` and count connections:
```cypher
MATCH (e) WHERE id(e) = toInteger($id)
OPTIONAL MATCH (e)-[r]-(connected)
WHERE connected:Person OR connected:Organization OR connected:Location
WITH e, collect({
  id: id(connected),
  name: connected.name,
  type: labels(connected)[0],
  rel: type(r)
}) as connections
RETURN e.name as name,
       labels(e)[0] as type,
       e.aliases as aliases,
       connections
```

2. **Add co-occurrence count** to the existing co-occurrences query (already returns `shared_docs`).

3. **Add a timeline events query** from Neo4j. Try to find Event nodes connected to the entity:
```cypher
MATCH (e)-[:PARTICIPATED_IN|OCCURRED_AT|RELATED_TO]-(event:Event)
WHERE id(e) = toInteger($id)
RETURN id(event) as id, event.date as date, event.description as description,
       event.type as event_type
ORDER BY event.date
LIMIT 50
```
If this returns no results, that's fine -- timeline_events will be an empty array. (Event extraction is Phase 6.)

4. **Add notes loading** from PostgreSQL (will be empty until 03-02 creates the table):
Try querying investigation_notes table. Wrap in try/catch -- if table doesn't exist, return empty array:
```sql
SELECT id, entity_id, content, created_at, updated_at
FROM investigation_notes
WHERE entity_id = $1
ORDER BY created_at DESC
```
Use the Neo4j entity ID (from URL params) as entity_id.

5. **Add biography loading** from PostgreSQL entities table:
```sql
SELECT description, metadata->>'biography_generated_at' as generated_at,
       metadata->>'biography_model' as model
FROM entities
WHERE canonical_name ILIKE $1
LIMIT 1
```
If found and `generated_at` is not null, return as EntityBiography. Otherwise null.
