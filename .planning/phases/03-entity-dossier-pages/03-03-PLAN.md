```typescript
interface Props {
  documents: Array<{
    id: string;
    filename: string;
    source: string;
    doc_type: string | null;
    file_size_bytes: number | null;
    created_at: string;
  }>;
}
```

State:
```typescript
let searchQuery = $state('');
let selectedDocType = $state<string>('all');
```

Derived data:
```typescript
// Extract unique doc_types for filter dropdown
const docTypes = $derived(() => {
  const types = new Set(documents.filter(d => d.doc_type).map(d => d.doc_type!));
  return ['all', ...Array.from(types).sort()];
});

// Filter documents by search query and doc_type
const filteredDocs = $derived(() => {
  let result = documents;
  if (searchQuery.trim()) {
    const q = searchQuery.toLowerCase();
    result = result.filter(d => d.filename.toLowerCase().includes(q));
  }
  if (selectedDocType !== 'all') {
    result = result.filter(d => d.doc_type === selectedDocType);
  }
  return result;
});
```

Layout:
1. **Filter bar** at top: flex row with gap-3
   - Input component (from shadcn) with placeholder "Search documents..." and bind:value={searchQuery}
   - Native `<select>` element styled with Tailwind (rounded-md border bg-background px-3 py-2 text-sm) for doc_type filter. Options from docTypes array. bind:value={selectedDocType}
   - Result count: `text-sm text-muted-foreground` showing "{filteredDocs.length} of {documents.length} documents"

2. **Document list**: space-y-3, each document as a clickable Card (existing pattern from current page):
   - Card with hover:bg-muted/50 transition
   - Link to `/documents/{doc.id}`
   - Card.Title: truncate(doc.filename, 80)
   - Card.Description: Badge for source, Badge for doc_type (if present), date, file size

3. **Empty states**:
   - No documents at all: "No documents found for this entity"
   - Search/filter returned nothing: "No documents match your filters" with a "Clear filters" button

4. **Pagination**: If documents.length > 50, show first 50 with "Load more" note. (Server already limits to 50 currently — full pagination is a future enhancement.)

Use the same Card/Badge patterns from the existing documents tab in +page.svelte. Import truncate, formatFileSize from $lib/utils.

function formatDate(dateStr: string): string {

    });
  } catch { return dateStr; }
}
