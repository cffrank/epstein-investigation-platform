**Search API changes** (`frontend/src/routes/api/search/+server.ts`):

1. Add entity filtering to `fulltextSearch()`: When `filters.entityIds` has entries, add a subquery to the WHERE clause:
```sql
AND id IN (
  SELECT de.document_id FROM document_entities de
  WHERE de.entity_id = ANY($N)
  GROUP BY de.document_id
  HAVING COUNT(DISTINCT de.entity_id) = {filters.entityIds.length}
)
```
This enforces AND logic -- results must mention ALL selected entities.

2. Add entity filtering to `semanticSearch()`: After fetching doc IDs from Qdrant and looking them up in PostgreSQL, add the same entity subquery to the PostgreSQL WHERE clause. This post-filters Qdrant results by entity. To compensate for filtering reducing results, fetch 3x the limit from Qdrant when entity filters are active.

3. `hybridSearch()` already delegates to the above two functions, so entity filtering propagates automatically.

4. Add a `populateEntities()` helper function that runs AFTER getting search results (before returning). For all result doc IDs, batch-fetch entities:
```sql
SELECT de.document_id, e.id, e.canonical_name as name, e.entity_type as type
FROM document_entities de
JOIN entities e ON e.id = de.entity_id
WHERE de.document_id = ANY($1)
ORDER BY de.mention_count DESC
```
Group by document_id in JS, map entity_type from lowercase to PascalCase (e.g., 'person' -> 'Person') using `initcap` style mapping. Attach top entities to each SearchResult's `entities` array. This replaces the hardcoded `entities: []`.

Call `populateEntities(platform, results)` in the POST handler after getting results from any search mode, before returning JSON.

**Entity Autocomplete endpoint** (`frontend/src/routes/api/entities/autocomplete/+server.ts`):

Create a GET endpoint that accepts `?q=` query parameter. Query PostgreSQL `entities` table directly (NOT Neo4j -- avoids ID mismatch per research):

```sql
SELECT id, canonical_name as name, entity_type as type
FROM entities
WHERE canonical_name ILIKE $1 || '%'
ORDER BY canonical_name
LIMIT 10
```

Map entity_type from lowercase to PascalCase in the response. Return JSON array of `EntityRef[]`. If `q` is empty or missing, return empty array.

Use the existing `query as dbQuery` from `$lib/server/db` and `validateSearchQuery` from `@epstein/shared` to sanitize input.
