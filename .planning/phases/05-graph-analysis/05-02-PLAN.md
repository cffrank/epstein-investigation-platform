**New interfaces** (add at top of file):
```typescript
interface AlgorithmResult {
  id: string;
  type: string;
  name: string;
  pagerank: number | null;
  communityId: number | null;
  betweenness: number | null;
  connections: number;
}

interface HiddenConnectionPair {
  personAId: string;
  personAName: string;
  personBId: string;
  personBName: string;
  sharedCount: number;
  topSharedNeighbors: Array<{ id: string; name: string; type: string }>;
}

interface CommunitySizeEntry {
  communityId: number;
  size: number;
}
```

**New state** (Svelte 5 $state runes):
- `colorMode`: `$state<'type' | 'community'>('type')` -- controls graph coloring
- `pagerankResults`: `$state<AlgorithmResult[]>([])`
- `communityResults`: `$state<AlgorithmResult[]>([])`
- `communitySizes`: `$state<CommunitySizeEntry[]>([])`
- `bridgeResults`: `$state<AlgorithmResult[]>([])`
- `hiddenConnections`: `$state<HiddenConnectionPair[]>([])`
- `algorithmStatus`: `$state<{ lastComputed: string | null; nodeCount: number }>({ lastComputed: null, nodeCount: 0 })`
- `computing`: `$state(false)` -- true while batch computation is running
- `activeAlgorithm`: `$state<string | null>(null)` -- which algorithm section is active/selected

**New functions:**

1. `loadAlgorithmStatus()` -- calls `callGraphApi('algorithm-status', {})`, updates `algorithmStatus`.

2. `loadPageRank(limit = 25)` -- calls `callGraphApi('pagerank', { limit })`, updates `pagerankResults`. Also sets `activeAlgorithm = 'pagerank'` and calls `loadAlgorithmEntities(results)` to auto-load top 20 into canvas.

3. `loadCommunities(limit = 25)` -- calls `callGraphApi('communities', { limit })`, updates `communityResults` and `communitySizes`. Sets `activeAlgorithm = 'communities'` and auto-loads top 20.

4. `loadBridges(limit = 25)` -- calls `callGraphApi('bridges', { limit })`, updates `bridgeResults`. Sets `activeAlgorithm = 'bridges'` and auto-loads top 20.

5. `loadHiddenConnections()` -- calls `callGraphApi('hidden-connections', {})`, updates `hiddenConnections`. Sets `activeAlgorithm = 'hidden-connections'`.

6. `triggerComputation()` -- sets `computing = true`, calls `fetch('/api/graph/compute', { method: 'POST' })`, on success reloads algorithm status, on error sets error. Always sets `computing = false` in finally.

7. `loadAlgorithmEntities(results: AlgorithmResult[])` -- takes first 20 results, converts to CytoscapeElement format (with id, label=name, type, connections, pagerank, communityId, betweenness), replaces current `elements` array (no edges, just nodes). This gives a clean canvas with just the top entities.

8. `loadHiddenConnectionPair(pair: HiddenConnectionPair)` -- loads both persons and their shared neighbors into the canvas as nodes, with edges between shared neighbors and each person (fetched via neighbors action for both persons). Add a synthetic dashed-edge element between the pair: `{ data: { id: 'hidden-${personAId}-${personBId}', source: personAId, target: personBId, label: 'hidden', lineStyle: 'dashed' } }`.

9. `setColorMode(mode: 'type' | 'community')` -- updates `colorMode`.

**New getters:**
- `getColorMode()`, `getPagerankResults()`, `getCommunityResults()`, `getCommunitySizes()`, `getBridgeResults()`, `getHiddenConnections()`, `getAlgorithmStatus()`, `getComputing()`, `getActiveAlgorithm()`

Also update the existing `CytoscapeElement` interface to include optional algorithm properties:
```typescript
interface CytoscapeElement {
  data: {
    id: string;
    label: string;
    type: string;
    connections?: number;
    pagerank?: number;
    communityId?: number;
    betweenness?: number;
  };
}
```

And update the `CytoscapeEdge` interface to include optional lineStyle:
```typescript
interface CytoscapeEdge {
  data: {
    id: string;
    source: string;
    target: string;
    label: string;
    lineStyle?: string; // 'dashed' for hidden connections
  };
}
```

**AlgorithmSection.svelte** -- Reusable accordion section for a single algorithm:
- Props: `title: string`, `results: AlgorithmResult[]`, `scoreKey: 'pagerank' | 'betweenness'` (which score to show in bar), `active: boolean`, `onActivate: () => void`, `maxResults: number` (default 10)

- Each entity card: rank number (1-based), entity name (as link to `/entities/{id}` that opens in new context, does NOT navigate away), type badge using `entityColor()` + entity type text, score bar (div with width proportional to max score in results, using tailwind bg-primary/20 background with bg-primary fill).

**HiddenConnections.svelte** -- Hidden connections pair list:
- Props: `pairs: HiddenConnectionPair[]`, `onLoadPair: (pair: HiddenConnectionPair) => void`
- Each pair shows: personA name and personB name side by side, shared neighbor count badge.
- Clicking a pair toggles an inline expansion showing shared neighbor names (name, type badge).
- "Load to graph" button on each pair calls `onLoadPair(pair)`.
- State: `expandedPair = $state<number | null>(null)` -- index of expanded pair.

**AnalysisSidebar.svelte** -- Main sidebar container:
- Props: none (reads from graphStore directly)
- Layout: `aside` with `w-72 border-r bg-background p-4 overflow-y-auto h-full` (wider than FilterSidebar to accommodate score bars).
- Header: "Analysis" title + status line showing "Last computed: {relative time}" or "Not yet computed" + "Refresh" button (calls `graphStore.triggerComputation()`). Show spinner on button when `computing` is true.
- Color mode toggle: Two buttons "Type" | "Community" styled as a segmented control. Calls `graphStore.setColorMode()`.
- Uses shadcn Accordion (type="single") wrapping:
  1. AccordionItem "PageRank" -- contains AlgorithmSection with `scoreKey='pagerank'`, `onActivate` calls `graphStore.loadPageRank()`, results from `graphStore.getPagerankResults()`.
  2. AccordionItem "Communities" -- contains AlgorithmSection with `scoreKey='pagerank'` (rank by influence within community), `onActivate` calls `graphStore.loadCommunities()`.
  3. AccordionItem "Bridge Nodes" -- contains AlgorithmSection with `scoreKey='betweenness'`, `onActivate` calls `graphStore.loadBridges()`.
  4. AccordionItem "Hidden Connections" -- contains HiddenConnections component, `onActivate` calls `graphStore.loadHiddenConnections()`.
- On mount, calls `graphStore.loadAlgorithmStatus()` to populate the "Last computed" timestamp.
- Entity click handler: calls `graphStore.selectNode(id)` then `graphStore.expandNode(id)`.
