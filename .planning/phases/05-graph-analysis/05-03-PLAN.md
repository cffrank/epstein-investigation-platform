**Community color utility** (define inside script):
```typescript
const COMMUNITY_PALETTE = [
  '#3b82f6', '#ef4444', '#22c55e', '#f59e0b',
  '#8b5cf6', '#06b6d4', '#ec4899', '#14b8a6'
];

function communityColor(communityId: number | undefined | null, sizes: Array<{ communityId: number }>): string {
  if (communityId == null) return '#71717a';
  const index = sizes.findIndex(s => s.communityId === communityId);
  if (index === -1 || index >= 8) return '#71717a'; // "Other"
  return COMMUNITY_PALETTE[index];
}
```

**Style modifications:**

1. **Node background-color** -- Replace the existing type-based color function:
```typescript
'background-color': (ele: cytoscape.NodeSingular) => {
  if (colorMode === 'community') {
    return communityColor(ele.data('communityId'), communitySizes);
  }
  const type = ele.data('type');
  switch (type) {
    case 'Person': return '#3b82f6';
    case 'Organization': return '#22c55e';
    case 'Location': return '#f97316';
    default: return '#71717a';
  }
}
```

2. **Node width/height** -- Replace existing connection-based sizing:
```typescript
width: (ele: cytoscape.NodeSingular) => {
  const pagerank = ele.data('pagerank');
  if (pagerank != null) {
    // Normalize against max in current graph
    const allPr = cy!.nodes().map(n => n.data('pagerank')).filter((v): v is number => v != null);
    const maxPr = Math.max(...allPr, 0.001);
    const normalized = Math.max(0, Math.min(1, pagerank / maxPr));
    return 20 + normalized * 40;
  }
  const connections = ele.data('connections') || ele.degree();
  return Math.max(20, Math.min(60, 20 + connections * 2));
}
```
Use the same function for height.

3. **Bridge node underlay** -- Add a new style selector AFTER the existing 'node' selector:
```typescript
{
  selector: 'node[betweenness]',
  style: {
    'underlay-color': (ele: cytoscape.NodeSingular) => {
      const betweenness = ele.data('betweenness');
      if (betweenness == null) return 'transparent';
      const allB = cy!.nodes().map(n => n.data('betweenness')).filter((v): v is number => v != null);
      const maxB = Math.max(...allB, 0.001);
      const threshold = maxB * 0.7; // top 30% get glow
      return betweenness >= threshold ? '#facc15' : 'transparent';
    },
    'underlay-padding': '8px',
    'underlay-opacity': 0.25,
    'underlay-shape': 'ellipse'
  } as any // underlay types may not be in @types/cytoscape
}
```

4. **Hidden connection dashed edges** -- Add edge selector:
```typescript
{
  selector: 'edge[lineStyle = "dashed"]',
  style: {
    'line-style': 'dashed',
    'line-dash-pattern': [6, 3],
    'line-color': '#a855f7', // purple-500 -- distinct from regular edges
    'target-arrow-color': '#a855f7',
    'target-arrow-shape': 'none', // no arrow for indirect connections
    width: 2
  }
}
```

**Reactivity for colorMode and communitySizes:**
Add an `$effect` that triggers a style update when `colorMode` or `communitySizes` change:
```typescript
$effect(() => {
  if (!cy) return;
  // Force Cytoscape to re-evaluate style functions
  const _mode = colorMode;
  const _sizes = communitySizes;
  cy.style().update();
});
```

This works because Cytoscape.js style mapper functions (the closures above) capture the outer scope variables. When those change and we call `cy.style().update()`, the functions re-evaluate with the new values.

IMPORTANT: The colorMode and communitySizes variables must be referenced directly in the style mapper closures (not just in the effect) so they are reactive. Since they are props, they update when the parent passes new values.
