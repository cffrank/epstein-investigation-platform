## BOTTLENECK IDENTIFICATION
1. OpenAI rate limits: grep "429" in logs → reduce RPM or upgrade tier
2. Database locks: SELECT * FROM pg_locks WHERE NOT granted;
3. Stalled workers: SELECT metadata->>'embed_worker_id', COUNT(*) FROM documents WHERE embedding_v2_started IS NOT NULL AND embedding_v2 IS NULL GROUP BY 1;
4. Reset stalled: UPDATE documents SET metadata = metadata - 'embedding_v2_started' WHERE embedding_v2_started < NOW() - INTERVAL '30 min';

## THROUGHPUT OPTIMIZATION
- Tier 2 (5000 RPM): ~30-45 minutes for 1.3M docs
- Calculation: 2.6M chunks / 20 per batch = 130K calls / 5000 RPM = 26 min + overhead
- 1-2 workers sufficient (rate limit is bottleneck, not parallelism)
- BATCH_SIZE=50 docs/claim, REQUESTS_PER_MINUTE=5000
- Index: CREATE INDEX idx_docs_embedding_pending ON documents ((metadata->>'text'), (metadata->>'embedding_v2')) WHERE metadata->>'text' IS NOT NULL AND metadata->>'embedding_v2' IS NULL;
